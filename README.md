## 🔬 Virtual Labs & Simulations

Free simulation platforms you can run in a browser — no equipment needed.

- [PhET Interactive Simulations](https://github.com/phetsims) — University of Colorado's world-standard science simulation suite. 150+ sims covering physics, chemistry, biology, and earth science. Browser-based, peer-reviewed. [Live: phet.colorado.edu](https://phet.colorado.edu/)
- [PhET HTML5 Source Repos](https://github.com/phetsims?q=html&type=public) — All individual simulation repos are open source. Good for understanding simulation architecture.
- [PhysicsHub](https://github.com/0xyd/physicshub) ⭐60 — Browser-based physics simulations: projectile motion, waves, optics.
- [Physics-Notebook](https://github.com/demidenko05/physics-notebook) ⭐280 — Interactive Jupyter notebooks covering classical mechanics, E&M, waves, and thermodynamics with live Python simulations.
- [sciencelab3d](https://github.com/rudra496/sciencelab3d) ⭐15 — 40+ interactive 3D STEM lab simulations running in-browser.

## ⚡ Physics — Visualization & Experiments

Python and web tools for simulating and visualizing physical phenomena.

- [AgentFEM](https://github.com/haoming-luo/agentfem) ⭐29 — Open-source finite-element workflows for learners ready to explore beam bending and heat transfer; [six guided exercises](https://lab.haoming-luo.com/learn/en.html) include prompts, reference results, and English, French, and Chinese handouts. Running new simulations requires installation.
- [diffractsim](https://github.com/rafael-fuente/diffractsim) ⭐1063 — Diffraction and wave optics simulator using the angular spectrum method. Produces stunning visualizations of double-slit, single-slit, and Fresnel diffraction.
- [N-body Simulation](https://github.com/rafael-fuente/N-body-numerical-simulation) ⭐76 — Gravitational N-body integrator in Python. Visualize how planets, stars, and galaxies evolve under gravity.
- [Computational Physics in Python](https://github.com/natsunoyuki/Computational_Physics_in_Python) ⭐27 — Clean code examples: pendulums, wave equations, Schrödinger equation, Monte Carlo methods. Each script is self-contained.
- [simba-ps](https://github.com/r-aristov/simba-ps) ⭐74 — Fast Lennard-Jones molecular dynamics simulator in pure Python/NumPy. See gas behavior and phase transitions emerge from particle interactions.
- [computational-physics](https://github.com/harvey2phase/computational-physics) ⭐51 — Student projects: orbital mechanics, fluid flow, electromagnetic fields — all Python.

## 🧪 Chemistry — Simulations & Datasets

- [PhET Chemistry Sims](https://phet.colorado.edu/en/simulations/filter?subjects=chemistry) — Acid-base titration, molecule shapes, atomic interactions, balancing equations — all browser-based.
- [Chemviz3D](https://github.com/BrokenCurves/Chemviz3D-3D_chemical_reaction_visualization) — 3D chemical reaction visualization built with React. See molecular collisions and bond formation.
- [RDKit](https://github.com/rdkit/rdkit) ⭐2800+ — Open-source cheminformatics toolkit. Draw molecules, predict properties, generate 3D conformers.
- [PubChemPy](https://github.com/mcs07/PubChemPy) ⭐400+ — Python wrapper for PubChem. Look up any compound's structure, properties, and safety data programmatically.
- [mendeleev](https://github.com/lmmentel/mendeleev) ⭐700+ — Python package: query the periodic table. Get electronegativity, ionization energy, atomic radii, electron configuration for every element.

## 🧬 Biology — Interactive Tools

- [PhET Biology Sims](https://phet.colorado.edu/en/simulations/filter?subjects=biology) — Natural selection, membrane channels, gene expression, neuron action potentials.
- [Biopython](https://github.com/biopython/biopython) ⭐4500+ — Standard toolkit for computational biology: parse DNA/protein sequences, run BLAST, visualize phylogenetic trees. Great for learning how genes and proteins actually work.
- [Galaxy Project](https://github.com/galaxyproject/galaxy) ⭐1500+ — Web platform for bioinformatics data analysis. Used by researchers to analyze genomic data without writing code.
- [ETE Toolkit](https://github.com/etetoolkit/ete) ⭐700+ — Build and visualize evolutionary trees in Python. Understand phylogenetics visually.

## 🔭 Astronomy & Space Science

- [Stellarium](https://github.com/Stellarium/stellarium) ⭐9859 — Real-time 3D planetarium. Renders the sky exactly as it appears anywhere on Earth on any date. Shows planets, stars, nebulae, and satellites. Available on desktop and web.
- [NASA Apollo 11 Source Code](https://github.com/chrislgarry/Apollo-11) ⭐72000+ — Original guidance computer source code that landed humans on the Moon in 1969. The most famous open-source codebase in history.
- [Skyfield](https://github.com/brandon-rhodes/python-skyfield) ⭐1400+ — Python astronomy library. Compute precise positions of planets, satellites, and stars. Great for writing your own planetarium or telescope controller.
- [AstroPy](https://github.com/astropy/astropy) ⭐4500+ — The standard Python astronomy library: coordinate transforms, FITS file processing, cosmological calculations.
- [N-body problem (edu)](https://github.com/rafael-fuente/N-body-numerical-simulation) ⭐76 — Same simulator as Physics section — try solar system setups and watch planetary orbits emerge.

## 📊 Data Science for Science Class

Use these to analyze your own experiment data like a scientist.

- [NumPy](https://github.com/numpy/numpy) ⭐28000+ — The foundation of scientific Python. Arrays, linear algebra, random numbers.
- [SciPy](https://github.com/scipy/scipy) ⭐13000+ — Integration, optimization, signal processing, statistics — the real scientific computing library.
- [Matplotlib](https://github.com/matplotlib/matplotlib) ⭐20000+) — Plot anything: measurement data, regression curves, error bars, heat maps.
- [pandas](https://github.com/pandas-dev/pandas) ⭐44000+) — Tabular data analysis. Load a CSV of experiment results, filter, group, and compute statistics in seconds.
- [Jupyter Notebooks](https://github.com/jupyter/notebook) ⭐11000+) — Write Python, see outputs inline with text and plots. The lab notebook of the 21st century.

## 🎬 Math & Science Animation

Make your own physics explanations and visualizations.

- [manim (3Blue1Brown)](https://github.com/3b1b/manim) ⭐90000+ — The original animation engine behind 3Blue1Brown's videos. Program mathematical animations in Python.
- [Manim Community](https://github.com/ManimCommunity/manim) ⭐40000+ — Actively maintained fork with better documentation, more features, and a large community. **Use this one for new projects.**
- [matplotlib.animation](https://matplotlib.org/stable/api/animation_api.html) — Built into Matplotlib. Animate any plot: oscillating pendulums, wave propagation, projectile trajectories.

## 🛠️ Maker Projects & Hardware

Real experiments, not just simulations.

- [Arduino](https://github.com/arduino/Arduino) ⭐13000+ — The open hardware platform for physical experiments. Measure temperature, light, sound, motion, and more with cheap sensors.
- [MicroPython](https://github.com/micropython/micropython) ⭐19000+ — Run Python directly on microcontrollers (ESP32, Raspberry Pi Pico). Build your own data loggers, environmental monitors, and robotic experiments.
- [OpenFlexure Microscope](https://github.com/rwb27/openflexure_microscope) ⭐600+ — 3D-printable microscope design. Achieves sub-micron positioning with printed flexure joints. Used in real research labs.
- [LabJack](https://github.com/labjack/labjack-ljm-python) — Python library for LabJack data acquisition devices. Used by schools to connect analog sensors to computers for measurement.
- [Raspberry Pi Sense HAT](https://github.com/RPi-Distro/python-sense-hat) — Python library for the Sense HAT add-on board: accelerometer, gyroscope, magnetometer, temperature, humidity, pressure — a full physics lab on a chip.

## 📚 Textbooks & Reference Notes

- [Physics Notebook (Jupyter)](https://github.com/demidenko05/physics-notebook) ⭐280 — Comprehensive physics notes with live Python code. Better than a static textbook.
- [Gaokao-Tools Physics & Chemistry Reference](https://github.com/daligao/gaokao-tools) — Offline quick-reference cards for Chinese high school physics (150 key points) and chemistry (145 key points). No login needed.
- [Feynman Lectures on Physics](https://www.feynmanlectures.caltech.edu/) — The greatest physics textbook ever written, free online. Caltech's official HTML edition.
- [HyperPhysics](http://hyperphysics.phy-astr.gsu.edu/hbase/hframe.html) — Concept map of all physics. Click any topic and get a clear explanation with diagrams. Best quick reference for high school and undergraduate physics.
- [Khan Academy Science](https://www.khanacademy.org/science) — Free video courses in physics, chemistry, biology, and earth science. Covers high school through AP level.

## 🧠 Scientific Thinking & Method

- [How to Think Like a Scientist (MIT OpenCourseWare)](https://ocw.mit.edu/courses/res-tll-004-stem-concept-videos-fall-2013/) — MIT STEM concept videos: measurement uncertainty, experimental design, data analysis, peer review. What science class should teach but often doesn't.
- [Statistics Done Wrong](https://www.statisticsdonewrong.com/) — Free online book. Explains p-values, statistical power, and common errors in scientific reasoning. Essential reading before you analyze any experiment data.
- [Measurement Uncertainty](https://github.com/uncertainty-toolbox/uncertainty-toolbox) ⭐1900+ — Python toolkit for calibrating uncertainty in predictions and measurements. Teaches the difference between "confident" and "correct."
